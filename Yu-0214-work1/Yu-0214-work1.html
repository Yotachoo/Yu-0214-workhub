关于我

你好!我是于琛博,目前的研究方向是 VLA(Vision-Language-Action) 与计算机视觉 —— 简单说,就是让模型既能“看懂”世界,又能据此做出动作。这是我最近投入精力最多的方向。

日常开发主要用 C++ 和 Python,在 Linux 环境下用 Git 管理代码, 机器人相关的部分会用到 ROS,同时也在学习强化学习。 平时习惯用 Claude Code、Codex 这类 AI 工具辅助开发,效率提升很明显。

这个页面是我在网页设计课上用 HTML 和 CSS 手写的第一个网页 —— 从标签结构到排版配色都自己敲了一遍。代码已托管在 GitHub 上, 现在世界上任何一台能上网的电脑都能打开它。
