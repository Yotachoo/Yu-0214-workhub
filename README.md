# Yu-0214-workhub

于琛博的网页设计课程作业集。每次作业使用独立目录保存，根目录为作业总入口。

## 在线访问

- [作业总入口](https://yotachoo.github.io/Yu-0214-workhub/)
- [第一次作业：个人主页](https://yotachoo.github.io/Yu-0214-workhub/Yu-0214-work1/Yu-0214-work1.html)
- [第二次作业：回响萨克斯社招新网站](https://yotachoo.github.io/Yu-0214-workhub/Yu-0214-work2/Yu-0214-work2.html)

提交课程作业时，请使用相应作业的网页访问链接，而不是 GitHub 仓库代码页的链接。

## 本地查看与发布

直接用浏览器打开根目录 `index.html` 即可选择作业。网页样式、脚本和媒体均保存在仓库内，不需要安装依赖或构建。

GitHub Pages 使用 `main` 分支的根目录作为发布源。仓库由 `Yu-0214-work1` 更名为 `Yu-0214-workhub` 后，第一次作业的访问链接已相应更新；先前提交过旧链接时，需要同步更新提交记录。

## 第二次作业说明

学号末位 4 对应萨克斯社。页面包含背景音乐、五个页内锚点与返回顶部、跨行跨列表格、图片超链接、`embed` 视频和十项表格内报名表。

报名表仅进行当前页面的校验与预览，不发送到服务器，也不持久保存个人信息。社团、活动和人物故事均为课程创作设定。图片由 AI 生成，音乐为原创合成配乐，视频由该图片制作；未冒称使用题目中列举的文心一言、海绵音乐或剪映生成。
